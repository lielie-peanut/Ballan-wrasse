# Ballan-wrasse
An R version of a Ballan wrasse population model previously realised in Excel, based on pre-existing published works.

**Author:** Laélie Huet laelie.huet@gmail.com

# Structure
You can find the R code in the R/ directory, and the model parameters and size limits in the data/ directory. The script used for results production is in the result/ directory along with relevant figures. 

You can find a quick walkthrough of the model in the "walkthrough" markdown file. It shortly introduces the reasons why this model is built as it is based on the model species' particularities, then goes over the construction and functioning of it, and details the results.

For in-depth information on the model construction, please refer to the original report "original Ballan wrasse modelling report". **NOTE:** the original report includes an error in the recruitment equation, as ϕ0 actually represents the unfished level of fertilised eggs per recruit, and not per reproducing female.
